# Spendge 视觉语言

> 状态：草案（2026-11-15） · 依据：示例 5–14 的风格探索稿 + 一轮讨论结论
>
> 上游：[product-plan.md](product-plan.md)（产品方向）、[architecture.md](architecture.md)（技术设计）。
> 本文只回答一个问题：**品牌情绪怎么落到界面上**。不排期（见 dev-plan），不重复产品论证。

## 0. 这份文档管什么

风格探索稿（示例 5–14）不是 UI 稿，是**材质、动词、落点**三样东西的探索。同一批图里 tab 出现了四种形态、tab 图标是不可用的假字形、柱状图刻度是乱码——它们只说明「想做成什么样」，不说明「该怎么画」。

因此本文只定三件事：**用什么材质、用什么动词、插画放在哪**。界面结构、交互、信息架构由我们自己设计。

## 1. 三条硬规矩

1. **插画只在停顿位**：空态、记账完成、月末回看、奖杯、达成。操作区（列表、表单、设置、图表）一律不加。
2. **每屏最多一个海绵**，且只有一种形态（3D 材质版）。不许海绵与「芝士」混用，不许线稿与渲染混用。
3. **颜色只管三层**：洗色底、白卡、深灰字。高饱和绿只给数字、主按钮、选中态。文字不加第三种强调色。

## 2. 材质

### 2.1 颜色 token

| Token | 现值 | 目标值 | 说明 |
| --- | --- | --- | --- |
| `canvas` | systemGroupedBackground（系统灰） | `#F2FDFA` 薄荷洗色 | 去掉「系统工具」感，这是情绪的主要来源 |
| `surface` | systemGray6 | `#EAF6F4` | 输入框、键盘、分段控件底；与洗色底同族但更实 |
| `surfaceElevated` | systemBackground（纯白） | `#FFFFFF` | 靠与 canvas 的明度差浮起，**默认不加投影** |
| `text` | .primary | `#1F2937` | 比纯黑柔，和品牌板的文字灰一致 |
| `textSecondary` | .secondary | `#6B7A78` | 板子写的 `#9CA3AF` 太浅，正文里读不清 |
| `accent` | `#14B8A6` | 不变 | 只给数字、主按钮、选中态、进度 |
| `accentSoft` | accent 12% | `#CCFBF1` | 选中底、标签底、淡填充 |
| `deepGreen` | — | `#0F766E` | **新增**。给需要压重量的文字（情绪句关键词、月度结论），用量极少 |

原则：**绿色是信号，不是底色**。大面积交给洗色底与白卡。

### 2.2 形状

| 元素 | 规格 |
| --- | --- |
| 卡片圆角 | 18 → **22** |
| 模块内的分组块 | 14 |
| 输入框、chip | 12 / 9（不变） |
| 按钮 | Capsule（不变） |
| 卡间距 | 12 → **14**；区块间距 28（不变） |
| 投影 | 不加。只有浮起元素（FAB、悬浮 dock、二级覆盖页）用轻投影（y 1、blur 3、4%） |

### 2.3 字阶

沿用 `Typography.swift`（14 个 token）。素材图里的字重比我们更轻——标题用 semibold，正文全 regular，不要再用 medium。情绪大句用 `hero`（26 / 行距 4），只在今天页出现一次。

## 3. 动词

这套隐喻（海绵吸水）能自洽的关键，是**动词和对象匹配**。

| 对象 | 用 | 不用 | 例 |
| --- | --- | --- | --- |
| 钱 | **接住** | 记录、管理 | 「这个月接住了 ¥3,200 的奶茶钱」 |
| 单笔花销 | **安放** | 保存、提交 | 「这花销，已经安放好了」 |
| 笔数 | **记下** | 安放（笔是数量，不是容器）、接住 | 「今天记下 3 笔」 |
| 超支 | **溢出** | 超标、超限、失败 | 「这个月有点溢出了」 |
| 达成 | **守住** | 完成、达成目标 | 「守住了一个月」 |

已有的产品文案（「今天还没记录」「本月有你 N 天的记录」）不改，除非重写整段。**不要为了用新动词而改所有文案**——只在新增和重写的文案里使用。

## 4. 落点

五个停顿位，各配一句、一张图。**这就是全部插画预算**。

| 场景 | 图 | 文案 | 频率 |
| --- | --- | --- | --- |
| 今天页空态（当天无记录） | 硬币沉入海绵，涟漪 | 今天还没记录 / 像海绵一样，把花销轻轻收好吧 | 每天可能看到 |
| 记账完成 | 硬币落定，涟漪一圈（动效 0.4s） | 已收好这笔 | 每次记账 |
| 月末回看（进入新月首次） | 海绵吸满，边缘有水痕 | 这个月接住了 N 笔 | 每月一次 |
| 我的奖杯（空态） | 干海绵，微微发光 | 还没收住什么，慢慢来 | 偶尔 |
| 预算超支 | 海绵溢出，水往下流 | 这个月有点溢出了 | 偶尔 |

要求：
- **空态不套卡片框**，插画直接浮在洗色底上（示例 6 的做法；示例 10 套了白卡，立刻变成模块，不要学）。
- 插画只有一种材质（3D 海绵），只出现这一个角色。
- 图表区、列表区、表单区**永远不放**。

## 5. 图标与 logo

### 5.1 App 图标

现在的水滴要换掉——水滴在金融类 App 里是最通用的形状，而且它表达的是「接住水」，与「吸收」相反。

| 项 | 规格 |
| --- | --- |
| 形状 | 四瓣柔和 blob，**3 个不等大、偏心的孔**（等大对称两孔 = 一张脸） |
| 底色 | 品牌绿满底 + 浅色形体（反白）。不要白底绿形体，主屏上会飘 |
| 材质 | 扁平矢量。3D 渲染只用于宣发，不做图标 |
| 变体 | light / dark / tinted 三套，同一份矢量派生 |
| 检查尺寸 | 1024 / 180 / 120 / 87 / 58 / 29（29 是设置页列表） |
| 禁止 | 文字、水滴、芝士黄、光晕、泡沫纹理 |

### 5.2 Logo

- 标记 + `spendge` 小写，一个元素。**去掉竖线分隔符**（那是导航标题的写法）。
- 「海绵记账」不进 logo，它是 App 名与 App Store 副标题。
- **待定**：对外主名用中文还是英文（见第 9 节）。中文为主时，`spendge` 退成小字副标。
- 字体必须是可商用字体（Nunito / Quicksand / Poppins 一类圆润几何体），AI 生成的 lettering 不能直接上线。

### 5.3 开屏

两张，不是一张：

| | 内容 | 约束 |
| --- | --- | --- |
| 系统启动图 | 洗色底 + 标记 | 只能是静态图，无动画、无按钮；系统会缓存 |
| 首启引导页 | 插画 + 一句 + 「开始记账」 | App 内页面，可动 |

## 6. 不做

| 不做 | 原因 |
| --- | --- |
| 每个目标卡放满屏插画 | 一张卡占 2/3 屏，三个目标要滚三屏，横向没法比较 |
| 「再喝一次，这个目标就守住啦」这类文案 | 暗示你快失败了，与「不制造压力」冲突 |
| 连续打卡类成就（「连续安放 7 天」） | 断一次归零的结构，已明确否掉 |
| 自绘全套 tab 图标 | 5 个 × 3 套成本高，25pt 下未必比 SF Symbols 清楚；只把「今天」换成一枚小海绵 |
| 手写悬浮 dock | iOS 26 的 TabView 原生就是悬浮胶囊；自绘会丢滚动手势、安全区、最小化、无障碍 |
| 图表里放装饰插画 | 示例 12 的芝士块摆在饼图旁边，纯噪音 |
| 黄色芝士形态 | 那是 AI 把海绵画成了奶酪。品牌只有一种多孔形态 |

## 7. 还缺的

- **深色形态**：探索稿全是浅色。要么明确锁 Light（写进 M5），要么海绵重新打光。
- **空月份的回看页**：目前只设计了有数据的样子。
- **超支视觉**：预算超了的呈现还没有。
- **失败态**：保存、导出失败。现在的 56 处 `try?` 静默失败，风格再好也补不上。

## 8. 落地顺序

| 步 | 内容 | 验收 |
| --- | --- | --- |
| 1 | 换颜色 token + 圆角（全站一处改动） | 截图对比：情绪是否真的来自底色。**这一步决定要不要继续** |
| 2 | 画一张「硬币入海绵」，在 5 个落点复用 | 5 屏截图，确认插画没有溢出到操作区 |
| 3 | 文案规约落地（接住 / 安放 / 溢出） | 新增文案不再出现「保存」「提交」 |

第 1 步完成后再谈 dock、tab 图标、目标卡结构——气质变了之后，这些判断会更准。

## 9. 待定

1. 对外主名：中文「海绵记账」为主，还是英文「Spendge」为主。
2. tab 数量：保持 4 个（借视觉），还是 5 个（把奖杯提成一级）。
3. 记账入口：留在页面右下 FAB（现状），还是抬进 dock。
4. 是否支持深色模式（影响第 2 步的插画打光）。
