# v1 上架清单（中国区）

> 目标：第一版快速上架验证产品。范围只含本地记账、iCloud 同步、崩溃上报、最小埋点；不做会员、账号、服务端解析。
> 状态：进行中 ｜ 更新：2026-11-23

## 0. 外部前置（不由代码决定，尽早启动）

- [ ] **App 备案**（工信部）：中国区上架必需，主体与 App 信息要一致
- [ ] **域名 / ICP 备案**：隐私政策、支持页如果挂在自有域名上，需要备案
- [ ] Apple Developer 账号与真机调试证书可用
- [ ] 隐私政策与支持页有可公开访问的 URL

## 1. 客户端阻塞项

- [x] **锁定浅色模式**：Info.plist 加 `UIUserInterfaceStyle = Light`（2026-11-24）
- [x] **隐私清单** `PrivacyInfo.xcprivacy`：已声明 UserDefaults（`CA92.1`）、崩溃/交互/设备标识的数据类型与用途，不跟踪（2026-11-24）
- [ ] **iCloud 同步**：CloudKit 容器、去唯一约束、默认值、冲突与墓碑、同步开关与状态、双设备测试
- [x] **最小埋点**：友盟+ 已接入（2026-11-24），9 个事件只记行为不记金额与备注；本地滚动日志同时保留；隐私政策 v2 与首启同意已更新
- [ ] **账号关联**：Sign in with Apple capability；开启 iCloud 时创建/绑定 accountId；服务端不可用不阻塞同步
- [ ] **App 内删除账号**：账号存在后的上架硬要求
- [ ] **诊断日志**：本地队列 + `/v1/diagnostics`，带 deviceId / accountId，不含财务内容
- [ ] **Bugly dSYM 上传**：Run Script 或手动上传，保证崩溃可读
- [x] **首启隐私页更新**：第三方服务从「崩溃」扩展到「崩溃与使用统计」，政策版本升到 2，首启重新同意（2026-11-24）
- [ ] 版本号与构建号、App 图标与启动屏最终确认
- [ ] Release 包确认没有开发者入口、无调试打印、无测试数据

## 2. App Store Connect

- [ ] App 记录、名称、副标题、描述、关键词
- [ ] 截图（6.7 / 6.5 / 5.5 英寸）

## 3. 数据与隐私

- [ ] 隐私政策包含：本地存储、iCloud（Apple 提供）、Bugly、友盟、诊断日志、账号标识、权限
- [ ] 第三方 SDK 清单：名称、提供方、用途、收集信息、初始化时机
- [ ] 首启同意覆盖全部第三方服务；同意后才初始化 SDK
- [ ] 不上传账单正文、备注、金额到自有服务端（本期没有服务端）
- [ ] 埋点参数不含财务内容与可识别身份的信息

## 4. 最小埋点事件

只用于判断「有没有人记、记完是否留下」，不做行为画像：

| 事件 | 说明 |
|---|---|
| app_launch | 启动 |
| onboarding_finish | 引导完成 / 跳过 |
| first_record | 第一笔记账 |
| record_save | 记账成功 / 失败（只记结果） |
| goal_create | 创建目标 |
| budget_set | 设置预算 |
| trophy_unlock | 奖杯解锁（只记 trophy id） |
| sync_result | iCloud 同步成功 / 失败（接 iCloud 后） |

## 5. 验收

- [ ] 新装 → 隐私同意 → 引导 → 记下第一笔，全流程无阻塞
- [ ] 飞行模式可记账、可查看；iCloud 不可用不阻塞
- [ ] 双设备同步：新增、编辑、删除都能收敛，无重复
- [ ] 备份导出 → 清空 → 恢复，数据完整
- [ ] 人为断网 / 服务异常，失败有顶部提示
- [ ] 真机连跑两天，Bugly 无新增崩溃
- [ ] TestFlight 内部测试通过后再提交审核
