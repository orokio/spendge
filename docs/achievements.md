# 成就体系

奖杯是「记录本身」的奖励，不是「省钱」的奖励。这条决定了哪些行为值得设奖杯。

## 三条原则

1. **阶梯而非散点**：同一件事做成多档（100 / 500 / 1000 / 5000 笔），让「再往前一步」一直存在。
2. **解锁即永久**：连续类中断只重新累计，已解锁的奖杯不收回。与「一次中断不否定此前积累」一致。
3. **稀有度有上限**：传说不超过 6 枚，否则贬值。

## 判定数据

- **累计 / 连续**：`Transaction` 按 `startOfDay` 去重计数
- **目标**：`GoalAchievement`，连续月份从最近一条往前数，断了即停
- **预算**：`Budget` 逐月对比当月实际支出
- **记录质量**：备注非空、分类去重数、当月天数覆盖
- **习惯**：`Transaction.createdAt` 的小时、与交易日期的时间差

每枚只需实现一个 `progress() -> (当前, 目标)`，三态卡的进度条和「还差 2 笔」直接取它。

## 页面：三态反差（2026-11-22 实现）

收集页的核心是状态反差，三态必须一眼区分：

| 状态 | 视觉 | 信息 |
|---|---|---|
| 已解锁 | 稀有度外壳实心 + 白色图标 + 右下角绿勾 | 名称 + 解锁日期 |
| 进行中 | 同色淡底 + 细描边 + 按进度画的弧 | 名称 + 「还差 5 天」 |
| 未解锁 | 灰色虚线空壳 + 问号 | 不显示名称 |

- **形状也承担状态**：实心 / 半环 / 虚线空壳，不看颜色深浅也能分清；色弱与强光下同样成立。
- **外壳按稀有度**：普通圆形、稀有六边形、传说星芒；图标用 SF Symbols，插画到位后只换内核。
- **进度只由徽章表达**：环已经画了完成比例，卡内不再加第二条进度条；卡上只留「还差 5 天」。
- **系列卡片**：每个系列的标题、解锁数与该系列徽章放在同一张卡里，组内保持阶梯顺序（100 → 500 → 1000 → 5000）。
- **顶部进度**：「已解锁 4 / 30」+ 普通 / 稀有 / 传说三条小进度；右上角「累计记录 4 天 · 最长连续 1 天」。只展示已发生的事实，不显示当前连续，避免断签焦虑。
- **hero 卡放「离解锁最近的一枚」**（进度 > 0 里完成度最高），不是最新解锁的那枚；最新解锁靠网格里的绿勾和日期表达。
- **未解锁不显示名称**：徽章中心已经是问号，名字留白，避免占位符和半露名字造成的不一致。
- **点任意卡开详情**：大徽章 + 达成条件 + 日期或进度；已解锁可分享（离屏渲染图片）。
- **解锁庆祝**：记账保存后检查，等记录页收起再全屏弹（可跳过）；一次解锁多枚按队列逐张展示。
- **入口**：目标页右上角奖杯图标。

## 实现

- `Models/Trophy.swift`：`TrophyID` / `TrophySpec` / `TrophyCatalog`（30 枚目录）+ `TrophyUnlock`（只存解锁日期）。
- `Services/AchievementService.swift`：一次扫描算出所需统计量（笔数 / 天数 / 连续 / 目标达成 / 预算 / 备注 / 分类 / 时段），再按 id 取（当前, 目标）；`refreshUnlocks` 幂等补写。
- `Views/AchievementView.swift`：奖杯墙、徽章（`TrophyBadge`）、详情弹层、分享卡、全屏庆祝。
- 解锁也进备份（`BackupFile.trophies`），清空数据一并清掉；SelfCheck 增加目录与文案校验。

## 未决

- **30 枚插画资源仍是零**：当前用稀有度外壳 + SF Symbols 跑通三态，插画只替换图标，不动结构。
- 称号体系（「稳稳星人」这类）需要单独定义，不在这一轮；首屏用「已解锁 x / 30」与稀有度分解代替。
- 长名在 3 列里的换行还没逐条复核（「连着三个月」「一百条备注」）。
