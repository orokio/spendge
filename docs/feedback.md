## 这次试用要看的三件事

1. **会不会主动点 ＋**：如果一周后每次都是「想起来才记」，问题在入口或时机，不在功能。
2. **那句话有没有一次「说到点上」**：十天里一次都没有，是句子规则的问题，不是模型。
3. **日期轴会不会记错天**：如果经常记到前一天，说明轴的视觉重心偏了。

## 五、已处理

> 2026-11-11 · 提交 `1e75297` · 验证后可以把上面原始条目删掉

**B 类**

- 收入下出现「冲动了」→ 记录面板移除冲动开关（字段保留在数据层，暂不暴露）。
- 半屏顶部太挤 → 顶部间距 16 → 28，并把「备注」固定在底部。

**E 类**

- 初始态两个动作并列 → 合并为一行「○ 今天没花钱」，点一下即确认。
- 「这 29 天我还没有你的记录」→ 覆盖率与缺口都改为按**已过天数**计算。
- 「本月覆盖 9%」不知道哪个月 → 回看页顶部显示「2026 年 11 月」。
- 回看页返回按钮 → 已移除，改为右滑返回。
- 时间轴看不出哪一天 → 加 1 / 5 / 10… 日期刻度，今天的柱子加深，且只画到今天。
- 缺历史月份入口 → 右下角新增月份按钮，可选最近 12 个月。
- 「记下」不可点时看不清 → 禁用态改为浅底 + 次要色文字。
- 分类要拖动才看得全 → 改为自动换行，11 个一屏可见（同时去掉图标腾空间）。
- 切换分类清空金额 → 手动输入过的金额会保留，只有没改过时才应用预填。
- 金额输入框不明显 → 加下划线与占位文案。
- 备注藏在「···」里 → 备注常驻底部，该按钮已删除。
- 现金账户多余 → 只有一个账户时不显示账户选择器。
- 首屏字体没情绪 → 数字改为品牌色、字重降为 medium（只做了轻调整）。

**第二轮（2026-11-11）**

- 金额没有小数点 → 不加小数点；**输入区一律显示「≈30」**。列表与汇总不加 ≈，避免满屏免责声明。
- 账户维度多余 → **取消多账户**：不支持信用卡 / 花呗，UI 不再暴露账户；两人共同记录（共享账本）列为未来方向，不是多账户。

**第四轮（2026-11-11）**

- 覆盖安装丢数据 → 不再按版本号无条件删库：**先尝试迁移，迁移失败才清库**。
- 「今天没花钱」无法取消 → 改成可逆：再点一下取消确认。
- 备注键盘收不起来 → 键盘上方加「完成」，并支持下滑收起。
- 渐变只出现在首页 → 提到根容器，两页共用。
- 月份按钮图标不协调 → 图标、文字、描边统一品牌色。
- 金额不好看 → 去掉币种符号、数字改品牌色、≈ 变灰色小字。
- 点金额多一步 → **键盘常驻**，不再需要先点金额。
- 分类太占空间 → 改为**键盘左侧的竖向标签列**（可滚动）。
- 收支距顶部太近 → 顶部间距加到 34，面板高度改为 73%。

**第三轮（2026-11-11）**

- 「冲动了」→ 字段一并删除，模型里不再有这一列（种子版本升到 7，旧库自动重建）。
