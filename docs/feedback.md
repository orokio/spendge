## 环境

- 设备 / 系统：iPhone 18 Pro Max · iOS 27.0
- 运行方式：Xcode 直接 Run（Debug 构建）
- 数据：本地 SwiftData，首次启动为空账本（种子版本变化时会自动清库）

## 这次试用要看的三件事

1. **会不会主动点 ＋**：如果一周后每次都是「想起来才记」，问题在入口或时机，不在功能。
2. **那句话有没有一次「说到点上」**：十天里一次都没有，是句子规则的问题，不是模型。
3. **日期轴会不会记错天**：如果经常记到前一天，说明轴的视觉重心偏了。

## 怎么记

只分三类，前缀固定，方便检索：

| 前缀    | 用途         | 例子                      |
| ----- | ---------- | ----------------------- |
| **B** | Bug / 明显不对 | B-001 点「记下」没反应          |
| **E** | 体验与感受      | E-001 那句「这周 2 次外卖」看了没感觉 |
| **I** | 想法 / 需求    | I-001 想按周看              |

一条一行就够，能定位就行；细节多的在下面补几行。
