# UI 框架规范（通用）

> 这是一套**与具体 App 无关**的默认规则：骨架、尺度关系、组件母版、交互约定。
> 项目实际取值（颜色、例外间距、图表参数）写在各自的界面规范里，本项目见 [visual-language.md](visual-language.md)。
>
> 目的：新项目复制四个 token 文件，照这份文档搭骨架；具体调参只改 token 层，不改页面。

## 0. 怎么用

复制这四样：

| 文件 | 作用 |
| --- | --- |
| `PageLayout` | 间距、圆角、页面边距 |
| `Typography` | 字阶角色 |
| `Palette` + `Color` 扩展 | 颜色语义 token |
| `Components` | `CardContainer` / `BackButton` / `TopDrawer` / `SecondaryPage` |

原则：

1. **数值只在一处定义**。页面里不写 `padding(17)`、不写 hex、不写 `.system(size:)`。
2. 这份文档给的是**默认值**。项目可以覆盖，但要保持相对关系（见第 2 节）。
3. 页面只负责组合，不负责微调。

## 1. 分层

```
token        间距 / 字阶 / 颜色        ← 唯一来源
components   卡片 / 行 / 按钮 / 抽屉   ← 只读 token
pages        组合 + 文案               ← 不写数值
```

## 2. 尺度关系

绝对值可以按品牌调，比例不要乱。

| 角色 | 默认值 | 关系 |
| --- | --- | --- |
| 页面边距 | 20 | ≈ 卡片内边距 |
| 行内间距 | 8 | 基准 1× |
| 块内间距 | 12 | 1.5× |
| 区块间距 | 28 | 3.5× |
| 卡片内边距 | 18 | 与页面边距同量级 |
| 行间距 | 10 | 紧凑列表基准 |

圆角阶梯：**卡片 22 > 行 18 > 模块 14**。永远保持递减，不要出现行比卡片更圆。

可覆盖的情况：

- 同权重的卡片连续堆叠时，卡片间距可以降到行间距（10），让页面更紧凑。
- 二级页的顶部起点由 `pageTopInset + backButtonSize + backToTitleGap` 推出（12 + 32 + 12 = 56），页面里不再手填。

## 3. 页面骨架

```
┌────────────────────────────────┐  ← 安全区下方
│  ← 12                            │  返回按钮 32
│  ↕ 12                            │  backToTitleGap
│  页面标题                        │  ← 从 56 开始
│                                │
│  区块 A                         │  ← 区块间距
│  区块 B                         │
│                                │
│  （二级页底部留出悬浮底栏的高度）   │
└────────────────────────────────┘
   ←20                       20→
```

- **不用系统导航栏**：标题画在内容里，避免导航栏重算安全区。
- **底部导航常驻**：二级页挂在所属 tab 的内容区，不盖住底栏；切 tab 时关闭二级页，回到该 tab 的根页。
- **返回按钮两种落位**：滚动页放在内容顶部（随内容滚走）；固定高度的编辑器（记一笔）浮在留白里，内容从 56 开始。
- 滚动页底部统一留 `tabBarClearance`（110），让最后一项能滚出悬浮底栏。
- 滚动条一律隐藏。

## 4. 组件母版

**卡片**

```
┌──────────────────────────────┐  圆角 22，白底，无描边、无投影
│ 小标题 15 semibold             │  内边距 18
│ 内容                          │
└──────────────────────────────┘
```

- 默认不加投影；投影只给 FAB、抽屉、浮层。
- 卡片内标题用 `bodyStrong`，页面级标题才用 `sectionTitle`。

**列表行**

```
[icon 32]  主文案 15 medium      数值 15 semibold
           副文案 13 gray
```

- 行外边距 h16 / v12，圆角 18（continuous），行距 10。
- 文字列固定高度，有无副文案都不跳。
- 数值列固定宽度、右对齐；宁可缩字也不换行。

**分段切换**

| 项 | 默认 |
| --- | --- |
| 轨道 | `surface`，圆角 10，内边距 3 |
| 选项高 | 32 |
| 选中 | 白底、圆角 8 |

**主按钮**：Capsule，`brand` 底，`onAccent` 文字，bodyStrong。

**FAB**：58 圆，右下 22 / 20，轻投影。

**返回按钮**：`backButtonSize`（32 × 32），`brand`。滚动页随内容；固定页浮在左上留白，距顶部 `pageTopInset`。

**顶部抽屉**：遮罩 `scrim`，底板只圆下两角（28），向上铺到屏幕最上沿。

**二级页容器 `SecondaryPage`**

```
SecondaryPage(onClose:) {
    scrollable: true          // 默认滚动；记一笔传 false
    swipeBackEnabled: true    // 浮层打开时可关掉
    backgroundColor: nil      // nil = 全局渐变底；记录页传 surfaceElevated
    backgroundTap: nil        // 记录页用来点空白收键盘
    content
}
```

容器负责：背景、返回按钮、顶部 `pageTopInset`、返回与标题间距 `backToTitleGap`、滚动页底部 `tabBarClearance`、右滑返回（水平位移 > 120 关闭，纵向手势不拦截）。

页面只写内容，不写背景、返回、偏移、手势；转场由路由层统一 `.move(edge: .trailing)` + `.geometryGroup()`。

## 5. 字阶角色

| 角色 | 用途 |
| --- | --- |
| `hero` | 首屏大句，一屏最多一次 |
| `pageTitle` | 页面标题 |
| `sectionTitle` | 页面级区块标题 |
| `number` / `numberSmall` / `numberLarge` | 卡片数字的三档 |
| `amountInput` | 大号数值输入 |
| `rowTitle` / `body` / `bodyMedium` / `bodyStrong` | 正文四档 |
| `label` / `caption` / `captionStrong` | 说明与角标 |
| `axisLabel` | 图表刻度 |

- 重量用 regular / medium / semibold；bold 只给数值输入与首页情绪句。
- rounded 只给标题和数字，正文用系统字体。

## 6. 颜色角色

| 角色 | 用途 |
| --- | --- |
| `brand` / `brandSoft` | 主操作、选中态、淡填充 |
| `danger` | 错误、删除 |
| `onAccent` | 强调色上的文字 / 图标 |
| `scrim` | 浮层遮罩 |
| `canvas` / `surface` / `surfaceElevated` | 底 / 控件底 / 卡片 |
| `textPrimary` / `textSecondary` | 两级文字 |

规则：

- 强调色是信号，不是底色。
- 业务数据色（分类、标签、领域）放在数据层，不进主题 token。
- 视图里不出现 hex。

## 7. 对齐与数字

- 标题、正文左对齐；结构化数值右对齐。
- 数值列固定宽度；标签在上、数值在下时两者都左对齐。
- 表格化的百分比列固定宽度、左边缘对齐。
- 币种、单位只在汇总处出现一次。

## 8. 可选模块：数据工具

只在列表 / 报表 / 统计型 App 里启用：

- 多列数值给每列固定宽度，右对齐。
- 行内进度条固定在数值列左侧，宽度小而恒定。
- 环图、图例、结构条、柱状图：先定阅读顺序，再定颜色；图例的百分比用固定列左对齐。
- 图表里不放装饰和插画，不加阴影。
- 叙事型 App 整节跳过。

## 9. 交互约定

- 行点击 = 查看 / 编辑；破坏性操作放长按或独立按钮。
- 抽屉、浮层关闭时同时收键盘。
- 空态只留一行灰字，不套卡片、不放大插画。
- 删除最后一条时自动退回上一级。
- 二级页统一右滑返回：水平位移超过 120 触发，纵向滑动交给内容滚动。

## 10. 不要做

| 不要 | 原因 |
| --- | --- |
| 视图里写 hex、`.red`、`.white`、`.system(size:)` | 全局搜索成本高 |
| 给卡片加投影 | 层级靠留白和底色 |
| 给页面套系统导航栏 | 安全区会把内容推下去 |
| 一屏两个强调色 | 信号失焦 |
| 卡片里放插画 | 插画只属于停顿位 |

## 11. 搭架子顺序

1. 建 `PageLayout` / `Typography` / `Palette` + `Color` 扩展
2. 放 `CardContainer` / `BackButton` / `TopDrawer`
3. 搭一个 tab 页骨架
4. 加一个右侧滑入页
5. 加一个顶部抽屉
6. 用真实文案填三个页面，再回头调间距
